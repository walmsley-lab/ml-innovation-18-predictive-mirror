# Research program · PR 01 — operational charter

**Status:** experimental charter, not evidence that intelligence has emerged.

## Question

Under which combinations of network structure, dynamics, environmental demand,
and physical cost do memory, prediction, adaptation, and coordinated behavior
become possible? Predictive Mirror is a controllable instrument, not the goal.

## Four scientific axes

1. **Structure:** locality, degree, graph distance, modularity, direction,
   state capacity, connectivity geometry.
2. **Dynamics:** update rule, noise, delay, recurrence, plasticity, coordination.
3. **Environment:** memory delay, communication distance, rule-switch frequency,
   ambiguity, observation noise, sensing availability, lesion fraction.
4. **Substrate:** local state, remote reads, message traffic, synchronization,
   memory hierarchy, measured versus estimated energy.

Measure *capability conditional on these axes*, never an unconditional
'intelligence score'.

## Operational emergence tests

| Test | Control | What a positive effect does **not** prove |
|---|---|---|
| Interaction dependence | Disabled/rewired edges, matched capacity | Biological equivalence |
| Collective nonlinearity | Independent units / additive surrogate | A unique causal mechanism |
| Capability transition | Multiple sizes and demands, identical task | Universal criticality |
| Self-organization | Fixed-rule, shuffled-feedback, global-learning floors | Open-ended intelligence |
| Causal mechanism | Matched lesions and recovery separation | Anatomical identity |

Register hypotheses **before** test outcomes. Use a matched noncollective
control and perturb the putative mechanism; a graph spectrum alone is not evidence
of functional emergence. A model can be scientifically informative even if it
does not win an RGB-prediction benchmark.

## Architecture portfolio

| Family | Primary experimental instrument |
|---|---|
| Independent units / linear estimator | Nulls and observability limits |
| Local cellular sheet | Spatial locality, recurrence and persistent state |
| Graph cellular model | Communication topology, long-range reach |
| Stochastic/phase-coupled network | Collective dynamical regimes |
| Compact SSM / recurrent model | State compression and temporal recall |
| CNN / motion transport | Strong conventional perceptual floors |
| Circuit or particle primitive | Local physical constraint and state movement |

An architecture is **active**, **frozen** or **archived with re-entry condition**.
Do not erase negative results. Additional expensive training requires a concrete
structural question, resource budget and the result that would justify re-entry.
Integrated models must declare mechanism membership and ablations.

## Evidence protocol

- Keep model-visible observations and actions separate from privileged truth.
- Split by physical-rule parameters, object combinations, sessions or topology,
  not only random episode seeds.
- Every run has a protocol version, source revision, seed, named controls,
  resource accounting and claim tier: **smoke**, **screen**, or **claim**.
- Screen runs identify possible effects; claim runs need a frozen protocol,
  independently replicated evaluations and uncertainty intervals.
- Preserve null results and report scope **at the tested scale**.
- Never conflate simulator, inferred mechanism and biological observation.

## Planned claim families

C1 structure×demand effects on capability; C2 persistent/causal world state;
C3 selective sensing and action utility; C4 cost of computation and data movement;
C5 structure–function identifiability; C6 agreement with measured neural evidence.

The evidence register is live from PR 01 onward, not assembled at the end.

## Cross-repository responsibility

- Predictive Mirror: standardized worlds, perception, active behavior and audit.
- Neuro Cellular Autonoma: minimal structural/dynamical mechanisms.
- Neural Dynamics: experimental neuroscience and measured recordings.
- Physical Computing / Hardware-Informed Models: measured devices and contracts.
Use small versioned result artifacts; do not duplicate frameworks. Respect
existing frozen hardware milestones and biological-data provenance requirements.

## Deferred / excluded for this initial stage

No claim of consciousness, general intelligence, biological correspondence,
real-world reliability, or physically measured efficiency follows from synthetic
toy experiments. Real-camera transfer is separately gated, not implied.

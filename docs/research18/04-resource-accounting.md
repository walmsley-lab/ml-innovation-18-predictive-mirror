# PR 04 — Communication and memory cost
This starts a dimensioned, abstract memory-hierarchy model. All costs
are modeled, with arbitrary, explicitly scenario-dependent weightings.
It records local/remote/offchip bytes, persistent state and a dense
arithmetic floor. No measurements of Tenstorrent or other physical chips
are claimed. Future cost studies must include attention-selection and
sparse-indexing overhead and report costs at matched task performance.

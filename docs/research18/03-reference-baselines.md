# PR 03 — Reference floors
Executable baseline utilities: persistence, delayed retrieval, causal
binary Bayesian filtering and a train-only affine state transition.
These supplement existing RGB baselines. ConvLSTM, compact SSM and SimVP
reference comparisons are **not yet implemented in this initial slice**.
A full campaign will require frozen inputs, matched resources and
unprivileged sensing under PRs 02 and 04. Never rank privileged-state
tracking with RGB-only methods as though inputs were equivalent.

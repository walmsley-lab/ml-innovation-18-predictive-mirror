# PR 02 — Capability contract and nonvisual battery
This is a dependency-free **fixture**, not a demonstration of intelligence.
Four deterministic tests: memory, routing, rule switch, and damage.
It separates model-visible observations from evaluator-only target/truth.
The frozen record schema tracks protocol, seed, condition, metrics, costs,
and provenance. World-configuration splits and real training/evaluation will
be completed before claim-level studies. Controls: independent units,
no-message, constant predictors, and Bayesian reference filters.
